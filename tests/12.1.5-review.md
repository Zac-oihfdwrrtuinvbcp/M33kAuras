# M33kAuras 12.1.5 compatibility review

Reviewed on 2026-10-15 against Blizzard's exported UI source:

- Baseline: [12.1.0 build 69933](https://github.com/Gethe/wow-ui-source/tree/09b9db7948abc9b9648dedaab51eb0cf3ee67b31).
- Target: [12.1.5 build 70340](https://github.com/Gethe/wow-ui-source/tree/12380f8cdc541b7f0963f74cbe0874c21a857fbb), from `ptr2`.
- [Source comparison](https://github.com/Gethe/wow-ui-source/compare/09b9db7948abc9b9648dedaab51eb0cf3ee67b31...12380f8cdc541b7f0963f74cbe0874c21a857fbb).

The review covers generated API documentation, deleted deprecation wrappers,
changed shared Lua helpers, and their callers in the addon, options, companion
modules, and local embedded library copies. Packaging fetches external libraries
according to `.pkgmeta`; these checks do not verify future upstream revisions or
custom code stored in users' saved auras.

## Changes made

All six addon TOCs now declare `120105, 16001`: core, options, archive, model paths,
templates, and the WeakAuras compatibility addon. Forever's interface is retained.

`GetArenaOpponentSpec` is documented with `SecretReturns = true` in the target's
[PvP API documentation](https://github.com/Gethe/wow-ui-source/blob/12380f8cdc541b7f0963f74cbe0874c21a857fbb/Interface/AddOns/Blizzard_APIDocumentationGenerated/PvpInfoDocumentation.lua).
The arena aura filter previously used that result as a selection-table key.
It now rejects a secret specialization before the lookup. Readable matching
specializations still work; missing, unknown, and unselected specializations do
not match. Leaving the filter unchecked avoids the specialization query entirely.
The option tooltip explains the restriction and how to continue tracking auras.

This is a compatibility finding from newly added documentation; the source diff
alone does not establish when the client first made the result secret.

## Changes requiring no adaptation in this checkout

| API change | Review result |
| --- | --- |
| Removal of 77 legacy currency, item, socket, LFG, pet, PvP, sound, trade, glue, and elapsed-timer wrappers/constants | No active references to the removed names. Item and currency calls already use their namespaces. `PickupTradeMoney` appears only in the custom-code blocklist. |
| Animation `QueryAnimationProgress` and `AddAnimations` restrictions | The addon and LibCustomGlow create their own animation groups. They do not supply groups to AuraContainer/AuraButton, where Blizzard applies these new restrictions. |
| Cooldown `Clear` and timing setters gain `IsProtectedFunction` | Icon regions create their own cooldown frames under ordinary addon frames. No writes to Blizzard's protected cooldown frames were found. |
| `PixelUtil.SetWidth`, `SetHeight`, `SetSize`, and `SetPoint` deprecated in favor of native pixel rounding | No callers of the deprecated setters. The border's `GetPixelToUIUnitFactor` remains available. |
| Native math/table helpers replace Lua implementations | Blizzard retains compatibility aliases for the helpers used here, including `Clamp`, `Round`, `tContains`, `tIndexOf`, and `tDeleteItem`. No migration is required. |
| `StringContains` removed; training-ground PvP functions renamed | No callers. `string.trim` remains available through the reorganized string API documentation. |
| Duration types renamed to `Seconds`/`Milliseconds`; cast bar IDs use `UnitCastBarID` | Existing call signatures and payload positions remain compatible. |
| Damage-meter `sourceGUID` becomes conditionally secret; new aura, locale, weather, and timer APIs | No affected callers or required migrations found. Existing aura secrecy predicates are unchanged. |

Relevant widget changes are documented in
[Animation](https://github.com/Gethe/wow-ui-source/blob/12380f8cdc541b7f0963f74cbe0874c21a857fbb/Interface/AddOns/Blizzard_APIDocumentationGenerated/SimpleAnimAPIDocumentation.lua),
[AnimationGroup](https://github.com/Gethe/wow-ui-source/blob/12380f8cdc541b7f0963f74cbe0874c21a857fbb/Interface/AddOns/Blizzard_APIDocumentationGenerated/SimpleAnimGroupAPIDocumentation.lua),
[Cooldown](https://github.com/Gethe/wow-ui-source/blob/12380f8cdc541b7f0963f74cbe0874c21a857fbb/Interface/AddOns/Blizzard_APIDocumentationGenerated/FrameAPICooldownDocumentation.lua), and
[AuraContainerUtil](https://github.com/Gethe/wow-ui-source/blob/12380f8cdc541b7f0963f74cbe0874c21a857fbb/Interface/AddOns/Blizzard_AuraContainer/Blizzard_AuraContainerUtil.lua).

## Validation

- `aura_scan_test.lua`: 23 assertions pass, including seven arena-filter cases.
  The new secret-value case reproduces the table-key error against unchanged HEAD.
- Full Lua 5.1 regression run: 34 of 36 test files pass. Both failures reproduce
  against unchanged HEAD: `aura_list_async_test.lua` lacks an `IsLoggedIn` stub,
  and `progress_texture_test.lua` has five existing rotation/pivot failures.
- All changed Lua files compile under Lua 5.1; `git diff --check` passes.

In-game verification remains necessary on 12.1.5: addon/module loading, opening
options, cooldowns and glows in combat, secret linear/circular progress, and arena
auras with the specialization filter enabled and disabled. Repeat module loading
and a basic aura check on Forever. Stubbed tests cannot establish native widget
permissions, rendering, or secret-value taint behavior.
